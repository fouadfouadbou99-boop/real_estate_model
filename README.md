# Real Estate Investment Analyzer

Application Streamlit permettant :

- Analyse immobilière
- Calcul TRI Projet
- Calcul TRI Equity
- VAN
- MOIC
- DSCR
- ICR
- Debt Yield
- Dashboard interactif
- Stress tests
- Export Excel
- Export PDF
- Export PowerPoint

## Installation

```bash
git clone https://github.com/username/real-estate-analyzer.git

cd real-estate-analyzer

pip install -r requirements.txt

streamlit run app.py
```

## Déploiement Streamlit Cloud

1. Pousser le projet sur GitHub
2. Connecter Streamlit Cloud
3. Sélectionner app.py
4. Deploy
